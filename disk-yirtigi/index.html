Disk yırtığı nədir?

Fəqərəarası disk yırtığı (latın dilində: hernia nuclei pulposi) — fəqərələr arasında yerləşən diskin daxili nüvəsinin xarici qişanı dələrək kənara çıxması vəziyyətidir. Bu zaman çıxan disk toxuması yaxınlıqdakı sinir kökünə və ya onurğa beyninə təzyiq göstərir, ciddi ağrı və nevroloji simptomlara səbəb olur.

Disk yırtıqları ən çox bel fəqərəsinin L4-L5 və L5-S1 səviyyəsində, boyun fəqərəsinin isə C5-C6 səviyyəsindəyarınır.

⚕️ Disk yırtıqlarının 90%-i əməliyyatsız müalicə olunur. Osteopatiya diskin üzərindəki mexaniki yükü azaldaraq sinir sıxışmasını aradan qaldırır.

Osteopatiya disk yırtığını necə müalicə edir?

Osteopatik yanaşmada disk yırtığı yalnız lokal problem kimi deyil, bütün hərəkat sisteminin disbalansının nəticəsi kimi qiymətləndirilir. Dr. Ülviyyə Süleymanova ilkin müayinədə onurğanın bütövlükdə vəziyyətini, çanaq simmetriyasını, ayaq uzunluğu fərqini və pəncə pozisiyasını qiymətləndirir.

Müalicə mərhələləri

  • 1-ci mərhələ (ağrı azaltma): Yumşaq toxuma texnikaları və fasyal relaksasiya ilə əzələ spazmı aradan qaldırılır, disk üzərindəki yük azaldılır.
  • 2-ci mərhələ (struktural korreksiya): Onurğa və çanaq hərəkətliliyi bərpa edilir, fəqərələr arası məsafə normallaşdırılır.
  • 3-cü mərhələ (stabilləşmə): Dərin stabilizator əzələlər aktivləşdirilir, sinir sistemi normallaşdırılır.

  • Ayaqda güc itkisi
  • Qasıq nahiyəsinin uyuşması

Tez-tez soruşulan suallar

Disk yırtığı əməliyyatsız müalicə olunurmu?

Bəli. Disk yırtıqlarının 90%-dən çoxu əməliyyat olmadan müalicə olunur. Osteopatiya yırtıq diskin üzərindəki yükü azaldır, iltihabı söndürür və sinir sıxışmasını aradan qaldırır.

Neçə seans lazımdır?

Adətən 6–10 seans tövsiyə olunur. İlk 3 seansdan sonra ağrı əhəmiyyətli dərəcədə azalır.

Disk yırtığı hansı əlamətlər verir?

Bel və ya boyunda kəskin ağrı, ayağa və ya qola yayılan ağrı (siyatika), uyuşma, zəiflik, hərəkət məhdudiyyəti.
